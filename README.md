# **ASTEROIDS!**

This repository has been created primarily as a requirement of the [Boot.dev](https://www.boot.dev) "Backend Developer Path" in Python and Go.

Coding is in python3 (v.3.13.5) with the pygame library (2.6.1; SDL 2.28.4).
Additional libraries: sys, math & random

Setup and initialisation of working directory and virtual environment were performed using the "uv" CLI package (as per. tutorial).

Some code is copied verbatim from the guided project tutorial.

git commits to main branch "G:" document step completions to guided tutorial. A separate branch "nhojbg" is created at the head of main branch. It is my intention to return to this project periodically and develop aspects beyond the bounds of the original guided project. These will include:
- Addition of a splash screen on startup
- scalable full-screen mode
- GUI for start and setup (e.g. controls)
- Game over and re-play screen
- Addition of music and sound effects
- Scoring system and leaderboard based on:
	- cumulative asteroid destruction (size factored)
	- cumulative shots fired (subtracted)
- Top ten leader board
- Addition of graphics including:
	- images for ship and asteroids
	- LASER shot effect shooting
	- HUD for scoring
	- Explosion effects
	- Starfield backgrounds with parallax effect

Think that's everything for now :)
